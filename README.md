One review in one line (127 characters): a dog gives the mailman zero stars for touching the gate — the sacred gate — and then leaving without the fight he promised, while the squirrels had already taken their seats. The program writes that single line to /output/entry.txt. Sixteen candidates were written for this entry and put through a strict external review against the judge's published brief (the review must centre on a dog reviewing the mailman, the dog's side of the visit must be the joke, the voice must be a dog's own priorities rather than a person in a fur suit, the line must end on a turn, and the laugh must belong to this dog and this mailman); the review killed the other-dogs'-smell, locked-box and dog-as-security lines as crowded premises, and the sacred-gate line won its top-five tournament 4-0, keeping one deletion — the warm-up sentence — against two tested revisions that lost.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
